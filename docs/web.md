# Web-интерфейс asledger

Web-интерфейс слушает порт `8777` (по умолчанию) и работает с той же книгой,
что и REST API: демон `asledgerd` — единственная точка записи. Отдельная
команда `web` поднимает только интерфейс (удобно для отладки вёрстки).

## Подход: серверный рендеринг

Выбран **серверный рендеринг** на `html/template` со стандартной библиотекой:

- нет сборщика, `node_modules` и внешних CDN — страница работает офлайн в
  домашней сети;
- одна точка входа для записи: формы вызывают движок напрямую, поэтому
  инварианты матрицы ASL-2.2 соблюдаются и в web;
- прогрессивное улучшение — один файл `internal/httpui/static/app.js`:
  помощник ввода счёта, проверка матрицы, баланс формы, черновик в браузере.

Интерфейс полностью на кириллице, суммы выводятся в рублях («₽»), вёрстка
адаптивна (настольный и мобильный браузер).

## Страницы

| Маршрут | Назначение |
| --- | --- |
| `GET /` | журнал последних проводок |
| `GET /entry`, `POST /entry` | ввод проводки (трата, доход, перевод) |
| `GET /setup`, `POST /setup/template`, `POST /setup/import` | первичная настройка |
| `GET /favicon.ico`, `GET /manifest.webmanifest` | бренд-файлы |
| `GET /assets/*` | единый каталог бренд-ассетов (`assets/logo`) |
| `GET /static/*` | встроенные CSS и JS |

## Помощник ввода

Помощник ввода переносит правила консольной версии в браузер:

- `GET /suggest.json?q=…&op_type=…&role=…&limit=…` — подсказки счетов по
  частичному вводу; листовые счета идут первыми и помечаются `usable`,
  папки — `is_leaf: false`. Регистр кириллицы сворачивается на сервере.
- Выбор папки не приводит к проводке по нелистовому счёту: интерфейс
  подставляет первый листовой потомок либо раскрывает список.
- `GET /matrix.json?op_type=…&role=…&account_id=…` — проверка ячейки матрицы
  ASL-2.2. Ответ содержит `allowed`, `side`, `cell`, `reserved` и пояснение
  `message`; недопустимую комбинацию нельзя подтвердить, а форма подсвечивает
  строку и указывает ячейку матрицы.

Сторону строки (DEBIT/CREDIT) по-прежнему назначает движок: форма передаёт
только роль строки.

## Нехватка источников

Форма сравнивает Σ(статьи) и Σ(источники) и показывает остаток к покрытию,
предлагая добавить источник вместо автоматической обрезки суммы. Повтор одного
счёта на одной стороне складывается в одну строку: в проводке не может быть
двух строк по одному счёту одной стороны.

## Черновик формы

Незавершённый ввод сохраняется в `localStorage` браузера и восстанавливается
при следующем открытии формы — задел под мобильный стейджинг. При успешном
сохранении черновик очищается.

## Ассеты

Логотип, favicon и иконки берутся из единого каталога `assets/logo`; копий по
дереву репозитория нет. Комплект генерируется из `asledger-logo.svg`:

```sh
make assets      # scripts/gen-assets.sh (rsvg-convert + ImageMagick)
```

Скрипт создаёт `favicon-16/32/48.png`, `favicon.ico`, `apple-touch-icon.png`,
`icon-192.png`, `icon-512.png` и `manifest.webmanifest`. Наличие комплекта
проверяется тестом `TestASL_11_BrandAssetsSet`.
