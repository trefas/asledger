# Коды валидации

Единый перечень машинных кодов ошибок asledger. Коды стабильны: по ним
реагируют web-интерфейс, REST API и Android-клиент, поэтому строку кода
менять нельзя — можно только добавлять новые.

Проверки движка собраны в одном месте — `pkg/core/engine` (функции
`Engine.Post` и `Engine.Reverse`). Слой данных (`pkg/core/store`) повторяет
инвариант баланса при записи и использует те же строки кодов.

## Коды движка (`pkg/core/engine`)

| Код | Когда возникает | Что показать пользователю |
| --- | --- | --- |
| `ERR_OP_TYPE_UNKNOWN` | Неизвестный тип операции | «Неизвестный тип операции» |
| `ERR_ACCOUNT_TYPE_UNKNOWN` | Неизвестный тип счёта в природе счетов | «Неизвестный тип счёта» |
| `ERR_UUID_EMPTY` | Не задан uuid проводки | «Внутренняя ошибка, повторите» |
| `ERR_UUID_DUP` | Проводка с таким uuid уже есть | Повтор не создаётся, возвращается прежняя проводка |
| `ERR_ENTRY_MISSING` | Не заданы обязательные строки операции | «Заполните операцию» |
| `ERR_ROLE_UNKNOWN` | Роль строки недопустима для операции | «Строка не подходит этой операции» |
| `ERR_AMOUNT_NOT_POSITIVE` | Сумма строки не положительна | «Сумма должна быть больше нуля» |
| `ERR_MATRIX_CELL` | Ячейка (операция, сторона, тип счёта) недопустима | «Такую строку нельзя добавить в операцию» + ячейка |
| `ERR_RESERVED_CELL` | Ячейка зарезервирована под post-MVP | «Функция появится в следующих версиях» |
| `ERR_UNBALANCED` | ΣDEBIT ≠ ΣCREDIT | «Суммы по сторонам не совпадают» |
| `ERR_ACCOUNT_NOT_LEAF` | В строке указана папка | «Выберите листовой счёт» |
| `ERR_ACCOUNT_ARCHIVED` | Счёт строки заархивирован | «Счёт в архиве» |
| `ERR_ACCOUNT_NOT_FOUND` | Счёт не существует | «Счёт не найден» |
| `ERR_SYSTEM_ACCOUNT` | Попытка задать служебную строку вручную | «Строка добавляется автоматически» |
| `ERR_DATE_RANGE` | Дата раньше создания счёта или больше «завтра» | «Проверьте дату операции» |
| `ERR_MIN_BALANCE` | Остаток уходит ниже `min_balance` в лимитном режиме | «Недостаточно средств на счёте» |
| `ERR_INITIAL_DONE` | Начальные остатки уже введены | «Стартовые остатки уже внесены» |
| `ERR_REVERSE_INVALID` | Отменяемая запись не найдена, уже отменена или сама — сторно | «Эту запись нельзя отменить» |
| `ERR_DIRECTION_REQUIRED` | Не задано направление переоценки/корректировки | «Укажите направление (рост/снижение)» |

## Коды слоя данных (`pkg/core/store`)

| Код | Когда возникает |
| --- | --- |
| `ERR_UNBALANCED` | ΣDEBIT ≠ ΣCREDIT при записи проводки |
| `ERR_AMOUNT_NOT_POSITIVE` | Неположительная сумма строки |
| `ERR_SIDE_INVALID` | Недопустимая сторона строки |
| `ERR_NO_LINES` | У проводки нет строк |
| `ERR_ACCOUNT_NOT_LEAF` | Счёт строки — папка |
| `ERR_ACCOUNT_ARCHIVED` | Счёт строки заархивирован |
| `ERR_ACCOUNT_NOT_FOUND` | Счёт строки не существует |
| `ERR_ACCOUNT_TYPE_MISMATCH` | Тип счёта-потомка не совпадает с типом родителя |

## Коды REST API (`internal/api`)

| Код | Когда возникает |
| --- | --- |
| `ERR_REQUEST_INVALID` | Некорректный запрос (тело, параметры, uuid) |
| `ERR_INTERNAL` | Внутренняя ошибка сервера |
| `ERR_ACCOUNT_NOT_FOUND` | В запросе указан несуществующий счёт |
| `ERR_RECONCILE_NOT_ADJUSTABLE` | Сверка пытается скорректировать доход или расход |
| `ERR_UNAUTHORIZED` | Нет или недействителен токен устройства |
| `ERR_ENROLL_FORBIDDEN` | Привязка устройства запрошена не из локальной сети |
| `ERR_ENROLL_DISABLED` | Привязка новых устройств запрещена настройкой книги |
| `ERR_ENROLL_NO_USERS` | В книге нет пользователей для привязки |
| `ERR_ENROLL_USER_REQUIRED` | Несколько пользователей, нужен выбор |
| `ERR_ENROLL_USER_UNKNOWN` | Передан несуществующий `user_id` |
| `ERR_OP_TYPE_UNKNOWN` | Неизвестный тип операции в `GET /engine/roles` |

## Как читать код в клиенте

`engine.Error` несёт, кроме кода, контекст: полный путь счёта (`Account`),
сумму (`Amount`), ячейку матрицы (`Cell`). Клиент показывает сообщение и
подсвечивает соответствующий счёт или строку.
