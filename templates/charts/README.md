# Шаблонные планы счетов

Готовые планы счетов в формате импорта JSON (вложенный формат `children`).
Каждый файл можно подключить:

- из web-интерфейса («Начать с шаблона»);
- командой `asledgerctl charts import <файл>`;
- через REST API импорта.

## Формат

```json
{
  "name": "Название шаблона",
  "accounts": [
    {
      "name": "Активы",
      "type": "актив",
      "min_balance": 0,
      "children": [
        { "name": "Наличные", "type": "актив", "min_balance": 0 }
      ]
    }
  ]
}
```

- `name` — короткое имя счёта без разделителя «:»;
- `type` — один из `актив`, `пассив`, `капитал`, `доход`, `расход`;
- `min_balance` — минимально допустимый остаток **в копейках** (0 для наличных,
  отрицательное значение — овердрафт); по умолчанию 0;
- `children` — вложенные счета; тип потомка обязан совпадать с типом родителя;
- `full_path` строится рекурсивно («Активы:Денежные:Наличные»).

Допускается и упрощённая форма — просто массив узлов верхнего уровня.

## Доступные шаблоны

| Файл | Описание |
|---|---|
| [`personal.json`](personal.json) | Личный бюджет: наличные, карта, накопления, базовые категории |
| [`family.json`](family.json) | Семейный с детьми: общие и личные карты, категория «Дети» |
| [`extended.json`](extended.json) | Расширенный: инвестиции, имущество, детализация расходов |

Все шаблоны включают служебные счета: «Капитал:Начальные»,
«Капитал:Корректировка», «Капитал:Переоценка» и ветку «Активы:Дебиторка».

Каждый файл проверяется тестом `TestASL_8_ChartTemplatesImport` — он проходит
импортёр без ошибок на обеих целевых платформах CI.
